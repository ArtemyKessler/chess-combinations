# Шахматы-комбинации

Вариант шахмат для двоих. Расстановка и ходы стандартные, но цель другая: собирать из своих фигур узоры из каталога и получать за них очки. Фигуры не снимаются с доски: взятая фигура уходит в резерв владельца, и он может снова выставить её на свои начальные горизонтали.

- **Играть:** откройте `index.html` в браузере или страницу GitHub Pages этого репозитория. Игра вдвоём за одним экраном. Интерфейс на английском и русском (переключатель EN/RU в шапке), фигуры можно двигать кликом или перетаскиванием, в том числе из резерва. Можно играть вдвоём или против бота за белых или чёрных.
- **Правила:** [RULES.md](RULES.md).
- **Расчёт очков:** [tools/solver](tools/solver) — перебор минимального числа ходов для каждого узора.
- **Симуляции:** [tools/sim](tools/sim) — движок без интерфейса и боты, которыми проверялся баланс правил.

## Структура

| Файл | Что это |
|---|---|
| `index.html` | Играбельный прототип, один файл без сборки |
| `RULES.md` | Текущая версия правил |
| `tools/solver/patterns.js` | Каталог узоров для расчёта |
| `tools/solver/solve.js` | Поиск минимального числа ходов (T) и стоимости сборки из резерва (R) |
| `tools/sim/` | Движок для симуляций, боты и запуск серий партий |

## Пересчитать очки

Нужен Node.js 18+.

```sh
node tools/solver/solve.js          # все узоры
node tools/solver/solve.js falanga  # один узор
```

Скрипт выводит для каждого узора T и R без короля и с королём рядом. Как из T и R получаются очки, описано в [RULES.md](RULES.md). Крупные узоры (Полк, Каре) считаются долго, до десятков минут.

## Публикация на GitHub Pages

Settings → Pages → Build and deployment → Source: **Deploy from a branch**, ветка `main`, папка `/ (root)`. Сборка не нужна.

## Симуляции

```sh
node tools/sim/run.js patient patient 10 1 '{"guard":true,"target":15}' > games.jsonl
python3 tools/sim/summ.py games.jsonl
```

Аргументы: бот за белых, бот за чёрных, число партий, начальное зерно, варианты правил в JSON. По умолчанию — правила v0.4; варианты включаются ключами `guard`, `banner`, `kingImmune`, `checkPts`, `target`. Боты: `random`, `greedy` (засчитывает сразу), `patient` (достраивает, если безопасно), `defender`, `builder`. Партия ботов занимает 10–20 секунд.
